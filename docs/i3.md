# i3 and picom rules

The toasts are a floating window, and i3 has to know it:

```
for_window [title="^nshell-toast$"] floating enable, border none, sticky enable
no_focus [title="^nshell-toast$"]
```

picom draws a shadow behind a transparent window and rounds its corners, which shows as a grey box around the cards:

```
{ match = "name = 'nshell-toast'"; shadow = false; corner-radius = 0; }
```
