# i3 and picom rules

The focus changes on a click and not when the pointer passes over a window. The popups, the history and the launcher close when they
lose the focus, so with the focus following the pointer they closed as soon as it left them:

```
focus_follows_mouse no
```

The toasts are a floating window, and i3 has to know it:

```
for_window [title="^nshell-toast$"] floating enable, border none, sticky enable
no_focus [title="^nshell-toast$"]
```

The history center is a window of its own, in the same corner. It takes the focus, to close with Escape:

```
for_window [title="^nshell-center$"] floating enable, border none, sticky enable
```

The menu of an icon of the tray is a window under the icon, which closes when it loses the focus:

```
for_window [title="^nshell-menu$"] floating enable, border none, sticky enable
```

The card of the polkit agent is a window of its own in the middle of the screen. It takes the focus, so that Escape cancels it
and the password can be typed:

```
for_window [title="^polkit$"] floating enable, border none, move position center
```

The launcher is a card in the middle of the screen. It takes the focus, so that the search field gets the keys:

```
for_window [title="^nshell-launcher$"] floating enable, border none, move position center
```

The volume on the screen is a window at the bottom that never takes the focus. The shell shows it when the volume of
the default output changes, so the keys only have to change the volume, and `wpctl` does it:

```
for_window [title="^nshell-osd$"] floating enable, border none, sticky enable
no_focus [title="^nshell-osd$"]
bindsym XF86AudioRaiseVolume exec --no-startup-id wpctl set-volume -l 1 @DEFAULT_AUDIO_SINK@ 5%+
bindsym XF86AudioLowerVolume exec --no-startup-id wpctl set-volume -l 1 @DEFAULT_AUDIO_SINK@ 5%-
bindsym XF86AudioMute exec --no-startup-id wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
```

Without the rule the window opens as a tile, as big as the screen.

The tabs of the tabbed containers are windows of the shell over the strip that i3 reserves, which i3 draws as nothing: the colors of
the tabs are transparent, with no title and no icon. The module writes this as `i3-<mode>.conf`; by hand:

```
client.focused          #00000000 #00000000 #00000000 #00000000 #00000000
client.focused_inactive #00000000 #00000000 #00000000 #00000000 #00000000
client.unfocused        #00000000 #00000000 #00000000 #00000000 #00000000
client.urgent           #00000000 #00000000 #00000000 #00000000 #00000000
client.placeholder      #00000000 #00000000 #00000000 #00000000 #00000000
client.background       #00000000
for_window [all] title_format " "
for_window [all] title_window_icon off
floating_minimum_size 1 x 1
for_window [title="^nshell-tabs-"] floating enable, border none
no_focus [title="^nshell-tabs-"]
bindsym $mod+s exec --no-startup-id nshell tabs list
```

The last line opens the list of the windows of the container that has the focus.

picom draws a shadow behind a transparent window and rounds its corners, which shows as a grey box around the cards:

```
{ match = "name = 'nshell-toast' || name = 'nshell-center' || name = 'nshell-menu' || name = 'polkit' || name = 'nshell-launcher' || name = 'nshell-osd'"; shadow = false; corner-radius = 0; },
{ match = "name *= 'nshell-tabs-'"; shadow = false; corner-radius = 0; }
```
